# Sprint_6
### Автотесты для проверки компонентов сервиса «Яндекс.Самокат»

### Реализованные сценарии

Проведены тесты:

test_unfolding_list.py - проверка элементов выпадающего списка

test_order_buttons.py - полное флоу оформления заказа через обе кнопки "Заказать" на главной странице, также проверяетя наличие всплывающего окна об успешном создании заказа

test_redirection.py - клик по лого Самоката ведет на главную страницу, а клик по лого Яндекса перенаправляет на страницу Яндекс Дзена

### Структура проекта

- `locators` - пакет, содержащий локаторы
- `pages` - пакет, содержащий файлы с классами страниц
- `tests` - пакет, содержащий тесты, разделенные по классам

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и формирование allure-отчета**

>  `$ pytest -v --alluredir=allure-results`
>  `$ allure generate allure-results -o allure-report --clean`

**Открытие allure-отчета в HTML**

>  `$ allure open allure-report`
