# Sprint_6
1. Основа для написания автотестов — фреймворк pytest.
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest tests/*название_теста*.py

Проведены тесты:
test_unfolding_list.py - проверка элементов выпадающего списка 
test_order_buttons.py - две кнопки "Заказать" на главной странице ведут на страницу заказа
test_order_success.py - после заполнении формы и оформлении заказа появляется всплывающее окно об успешном создании заказа
test_redirection.py - клик по лого Самоката ведет на главную страницу, а клик по лого Яндекса перенаправляет на страницу Яндекс Дзена
